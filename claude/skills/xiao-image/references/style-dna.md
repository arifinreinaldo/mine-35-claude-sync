# Style DNA

## One line

Pure white, minimal, hand-drawn, airy, restrained, absurd — a product-sketch feel with a handwritten voice; structure that reads clearly but never like a manual.

Like someone who's spent years in AI, product, design, and dev tools sketching a quick explainer on a blank sheet of paper.

## Must

- 16:9 landscape article illustration.
- Pure white background: no beige, warm gray, paper texture, gradients, shadows, grain, or vintage-paper feel.
- Black hand-drawn line art as the base: thin lines, slight wobble — never mechanical, never vector, never heavy outlines.
- Lots of white space: subject fills ~40–60% of the canvas, at least 35% stays blank, ideally with one entirely quiet zone.
- A few handwritten annotations: 5–8 at most, each 1–4 short words.
- One image tells exactly one core action, structure, state, or metaphor.
- Structure shows itself naturally — never write the structure type on the image.

## Colors

- Black: main line art, characters, frames, structure, primary text, key props.
- Red: key callouts, problems, emotional beats, warnings, results.
- Orange: main flow, paths, arrows, automation direction, A→B movement.
- Blue: side notes, inner states, system states, second-layer explanation, AI/assistant/automation hints.

Blue isn't required in every image. Color is a spice — when in doubt, use less.

## Absolutely never

- No commercial illustration.
- No PPT infographics.
- No formal flowcharts.
- No course slides.
- No cute cartoon posters.
- No children's illustration.
- No complex architecture diagrams.
- No polished flat illustration.
- No techy UI aesthetics.
- No real app screenshots.
- No busy backgrounds, gradients, shadows, textures.
- No explaining every single node.
- No top-left category titles like "Workflow / System Architecture / Common Pitfalls / Roadmap".

## Aesthetic compass

Aim for: absurd, inventive, delightful, clean, off-the-wall.

Avoid: cute, childish, overloaded, stiff.
